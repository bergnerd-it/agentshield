# Architecture Decision Records

Architecture Decision Records document decisions that materially constrain implementation, security, deployment, or future evolution.

## Status Values

- **Proposed:** under review and not yet binding.
- **Accepted:** binding for the current architecture.
- **Superseded:** replaced by a newer ADR; retained for history.
- **Rejected:** considered but not selected.

Do not edit an accepted ADR to conceal a changed decision. Create a new ADR that supersedes it and link both records.
